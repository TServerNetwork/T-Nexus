# 資源ワールド Schematic 運用マニュアル

## 目的

このドキュメントは、資源ワールドのリセット時に使用する `spawn.schem` の配置ルールと、地形整形の挙動をまとめたものです。

## 配置場所

- 配置先: `plugins/T-Nexus/schematics/<worldName>/spawn.schem`
- 例: `plugins/T-Nexus/schematics/resource/spawn.schem`

## リセット時の挙動

- `spawn.schem` が存在する場合、T-Nexus は先に schematic の外形を読み取ります。
- schematic 本体の周辺は平坦化されます。
- その外周は自然地形へ段差が出にくいよう、ブレンドしてなじませます。
- schematic は `(0, surfaceY, 0)` を基準に貼り付けられます。

## schematic が無い場合の挙動

- `spawn.schem` が存在しない場合でも、リセット自体は続行されます。
- `(0, 0)` を中心に、半径 `8` の円形ベースを生成します。
- 円形ベースの外周は自然地形へブレンドされます。

## schematic 作成時のルール

- `(0, 0, 0)` をスポーン基準点として扱ってください。
- schematic の原点は、リセット後の地表面に載せたい位置へ合わせてください。
- 建物の壁、階段、張り出し装飾が地形ブレンドと干渉しないよう、周囲に余白を持たせてください。
- schematic の外側が完全なフラット地形になる前提では設計しないでください。
- 入口や床の高さを厳密に合わせたい場合は、原点位置と床面の設計で吸収してください。

## 補足

- schematic ファイルが無い場合は、円形ベース生成にフォールバックします。
- schematic の形式が不正、または FAWE 側で読めない場合は、通常のリストアフローでリセット失敗として扱われます。
